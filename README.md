# RINGSIDE — ทุกจังหวะ คือมวยไทย

เว็บไซต์มวยไทยภาษาไทยใน `index.html` พร้อมวิดีโอพื้นหลัง Wan 3.0 และ “อัคนี” ตัวละครนักมวย 3D ที่หมุนดูได้ รองรับมือถือและคอมพิวเตอร์

## เปิดเว็บไซต์

```sh
python3 -m http.server 8013
```

เปิด http://localhost:8013 ใช้ static hosting ได้โดยไม่ต้อง build หรือใส่ API key ฝั่งผู้ชม การดูโมเดล 3D ต้องใช้เบราว์เซอร์ที่รองรับ WebGL; มีภาพ poster สำรอง

## ไฟล์สำคัญ

| ไฟล์ | เนื้อหา |
| --- | --- |
| `index.html` | หน้าเว็บ, CSS และการควบคุมวิดีโอ/โมเดล |
| `web-assets/wan-muaythai-bg.mp4` | Wan 3.0, 1920×1080, 30 fps, 6 วินาที, ไม่มีเสียง |
| `web-assets/blender-reference.mp4` | คลิปอ้างอิง Blender, 1280×720, 24 fps, 144 เฟรม |
| `web-assets/akhani.glb` | โมเดลอัคนี พร้อม rig 22 กระดูกและ Guard_Idle |
| `assets/muay-thai-fighter/akhani-hero.blend` | ต้นฉบับโมเดลอัคนีที่แก้ไขต่อใน Blender ได้ |
| `assets/muay-thai-fighter/motion-prototype/muay-thai-motion.blend` | ฉากต้นฉบับการ์ด → แย็บ → เตะ → กลับสู่การ์ด |
| `scripts/check_website.cjs` | ตรวจ JavaScript, assets, anchors และขอบเขตจังหวะวิดีโอ |

## การสร้างสื่อ

สร้างและเรนเดอร์ Blender เป็น PNG ต่อเนื่อง 144 เฟรม แล้วรวมเป็น MP4 ก่อนส่งคลิปจริงเป็น `video_urls` / `@Video1` ให้ Wan 3.0 ผ่าน Phaya เมื่อ 2026-09-09 โดยกำหนดกล้องสามส่วนแบบคงที่ แย็บที่ 1.625 วินาที และเตะหน้าที่ 3.958 วินาที

วิดีโอ Wan เป็นฉากที่ AI สร้างขึ้น นักมวยและอัคนีเป็นตัวละครสมมติ รูปลักษณ์ในวิดีโออ้างอิงข้อความบรรยาย จึงไม่รับประกันว่าใบหน้าจะเหมือนโมเดล 3D ทุกจุด ท่าสุดท้ายใกล้เคียงท่าเริ่มต้นแต่ไม่ใช่ลูปที่ตรงกันทุกพิกเซล และมีลายคล้ายตัวอักษรบนกางเกงที่ระบบสร้างขึ้น

## ตรวจสอบ

```sh
node scripts/check_website.cjs
```

ใช้ `<video>` และ `<dialog>` ของเบราว์เซอร์ และ model-viewer 4.3.1 ที่เก็บไว้ในโปรเจกต์ ฟอนต์ Anuphan และ Barlow Condensed อยู่ใน `web-assets/vendor/` พร้อมใบอนุญาต OFL; model-viewer มีใบอนุญาต Apache 2.0 ในโฟลเดอร์เดียวกัน ไม่มี CDN หรือ API ของระบบสร้างวิดีโอที่ผู้ชมต้องเรียกใช้
