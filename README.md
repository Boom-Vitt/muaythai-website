# RINGSIDE — AKHANI / THE FLAME WITHIN

เว็บไซต์มวยไทยภาษาไทยใน `index.html` ใช้ภาพและภาพยนตร์ของ “อัคนี” พระเอกแอนิเมชันในสนามมวยไทยแฟนตาซีเป็นภาพหลัก พร้อมไฟต์แล็บ 3D ด้านล่างสำหรับหมุนดู เล่นซ้ำ และหยุดดูท่าต่อสู้ รองรับมือถือและคอมพิวเตอร์

สถานะ 2026-09-12: ภาพยนตร์ cinematic ฉบับเต็มเรนเดอร์สำเร็จ ตรวจไฟล์ ภาพตัวอย่าง และการใช้งานเว็บบนคอมพิวเตอร์กับมือถือผ่านแล้ว คลิป Blender ใช้อ้างอิงการเคลื่อนไหวเท่านั้น รูปลักษณ์ตัวละคร เสื้อผ้า ฉาก และแสงมาจากภาพ `assets/muay-thai-fighter/h3-cinematic/akhani-keyframe.png`

## เปิดเว็บไซต์

```sh
python3 -m http.server 8013
```

เปิด http://localhost:8013 ใช้ static hosting ได้โดยไม่ต้อง build หรือใส่ API key ฝั่งผู้ชม การดูโมเดล 3D ต้องใช้เบราว์เซอร์ที่รองรับ WebGL; มีภาพ poster สำรอง

## การสร้างสื่อ

ทิศทางใหม่เมื่อ 2026-09-12 ใช้ MiniMax H3 Ref2VA ผ่าน native `h3.c` บน Apple Silicon รูปลักษณ์พระเอก สัดส่วน เสื้อผ้า วัสดุ สนามมวยไทยแฟนตาซี และแสงสีอำพันตัดน้ำเงิน อ้างอิงจาก `akhani-keyframe.png` ที่สร้างด้วย Imagegen ผ่าน `--ref-image` ส่วน `--ref-silent-video` รับ `motion-only-reference.mp4` ซึ่งเป็นคลิป Blender ขาวดำ 224×128 สำหรับลำดับท่า การถ่ายน้ำหนัก และจังหวะเท่านั้น ห้ามนำรูปลักษณ์โมเดลหรือสตูดิโอ Blender มาใช้เป็นภาพปลายทาง

งานเต็มใช้ seed `38471`, 20 steps, 50 layers และ SSD streaming ผ่าน runtime `antirez/h3.c` รุ่น `8974cc0` พร้อมภาพ `akhani-keyframe.png` และคลิป `motion-only-reference.mp4` เป็นสื่ออ้างอิง ผล native มี 243 เฟรม / 10.125 วินาที พร้อมเสียง จากนั้นตัดช่วงค้างท้าย 3 เฟรมและเสียง ได้คลิปเว็บ H.264 ขนาด 3,360,307 ไบต์, 1024×576, 24 fps, 240 เฟรม / 10 วินาที

ทั้งไฟล์ native และคลิปเว็บผ่านการ decode ครบคลิป การดูภาพตัวอย่าง 30 จังหวะและอีก 24 ภาพช่วงกระโดดพบรูปลักษณ์พระเอกและสนามวัดตาม keyframe ใหม่ หมัดที่แตกต่างกัน การยกขา/เตะ การ์ดกลางอากาศ และการลงพื้น H3 ตีความจังหวะเข่าในต้นแบบเป็นท่ายกขา/เตะ จึงไม่ได้ทำซ้ำทุกอาวุธหรือเวลาของ Blender แบบเฟรมต่อเฟรม และรอยต่อลูปไม่ตรงกันทุกพิกเซล ปุ่มเลือกท่าในไฟต์แล็บซิงก์กับโมเดลและคลิป Blender โดยตรง

รายละเอียดการสร้าง สื่ออ้างอิง พรอมป์ต์ และบันทึกผลตรวจอยู่ใน `assets/muay-thai-fighter/h3-cinematic/README.md` และ `validation.json` ในโฟลเดอร์เดียวกัน หลักฐานที่เผยแพร่ประกอบด้วย keyframe, พรอมป์ต์, คลิป motion-only และผลตรวจ ส่วนคลิปทดสอบสไตล์ เอาต์พุต native และบันทึก runtime เก็บไว้ในเครื่อง ไม่จำเป็นต่อการใช้งานเว็บไซต์ ตัวเลือก H3 ก่อนหน้าที่ผู้ใช้ปฏิเสธไม่รวมในสื่อที่นำเสนอครั้งนี้

### เวอร์ชันแรก

สร้างและเรนเดอร์ Blender เป็น PNG ต่อเนื่อง 144 เฟรม แล้วรวมเป็น MP4 ก่อนส่งคลิปจริงเป็น `video_urls` / `@Video1` ให้ Wan 3.0 ผ่าน Phaya เมื่อ 2026-09-09 โดยกำหนดกล้องสามส่วนแบบคงที่ แย็บที่ 1.625 วินาที และเตะหน้าที่ 3.958 วินาที

วิดีโอ Wan เป็นฉากที่ AI สร้างขึ้น นักมวยและอัคนีเป็นตัวละครสมมติ รูปลักษณ์ในวิดีโออ้างอิงข้อความบรรยาย จึงไม่รับประกันว่าใบหน้าจะเหมือนโมเดล 3D ทุกจุด ท่าสุดท้ายใกล้เคียงท่าเริ่มต้นแต่ไม่ใช่ลูปที่ตรงกันทุกพิกเซล และมีลายคล้ายตัวอักษรบนกางเกงที่ระบบสร้างขึ้น

## ตรวจสอบ

คอมโบปรับใหม่เมื่อ 2026-09-12: แย็บ → ตรง → แย็บ → ตรง → ฮุก → อัปเปอร์คัต → ฮุก → ตรง จังหวะหมัดอยู่ที่เฟรม 24/35/48/62/78/95/113/132 ที่ 30 fps ต่อด้วยเข่าที่เฟรม 175 หมัดกระโดด 215 การ์ดกลางอากาศ 240 และลงพื้น 265 ก่อนกลับเข้าการ์ด รวม 10 วินาที ออกแบบท่าเองตามคำขอ รายละเอียดการสร้างและตรวจอยู่ใน `assets/muay-thai-fighter/combat-v2/README.md` คลิป Blender และ GLB ชุดนี้พร้อมใช้งาน ภาพยนตร์ cinematic พื้นหลังชุดใหม่ผ่านการตรวจไฟล์และภาพตัวอย่างแล้ว และ `node scripts/check_website.cjs` ผ่านเมื่อ 2026-09-12; ตรวจวิดีโอจริง ปุ่มชมภาพยนตร์ ปุ่มเลือกท่า เมนูมือถือ และขนาดหน้าจอ 1440×900 / 390×844 ผ่านโดยไม่มี console warning/error หรือเนื้อหาล้นแนวนอน

สร้างจากไฟล์ `akhani-hero.blend` เดิมด้วย Blender 5.2.1:

```sh
blender --background --python-exit-code 1 --python scripts/improve_boxing.py -- --render
```

```sh
node scripts/check_website.cjs # ต้องมี ffprobe; ตรวจ Blender 300 เฟรม และ cinematic 240 เฟรม รวมคลิปละ 10 วินาที
```

ใช้ `<video>` และ `<dialog>` ของเบราว์เซอร์ และ model-viewer 4.3.1 ที่เก็บไว้ในโปรเจกต์ ฟอนต์ Anuphan และ Barlow Condensed อยู่ใน `web-assets/vendor/` พร้อมใบอนุญาต OFL; model-viewer มีใบอนุญาต Apache 2.0 ในโฟลเดอร์เดียวกัน ไม่มี CDN หรือ API ของระบบสร้างวิดีโอที่ผู้ชมต้องเรียกใช้
